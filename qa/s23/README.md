# S23 — Accesibilidad automática

Fuente normativa: Suite exhaustiva v2.0, Fase 17.

Gate automático:
- axe en vista principal con teclado cerrado y abierto;
- cero violaciones critical/serious no justificadas;
- teclas unavailable con aria-disabled="true";
- tabs y diálogo con rol/nombre accesible;
- foco entra al diálogo y vuelve al disparador al cerrar con Escape;
- resultado dinámico anunciado como status/live;
- error dinámico anunciado como alert/live assertive.

La pasada manual asistida con lector de pantalla queda para S24.
