# IN625 H1 — Reentrada / output-as-input

Contrato: evaluar entrada -> obtener salida S1 -> reingresar S1 -> obtener S2. Pasa si S2 entra sin error y es un punto fijo matemáticamente equivalente a S1.

## Plan de ejecución
- H1a: EN-RE-01..08 — reentrada básica de valores/símbolos.
- H1b: EN-RE-09..16 — integrales, soluciones, intervalos, matrices, aproximaciones, notación científica y agrupación.
- H1c: EN-RE-17..23 — locale, aliases españoles, ASCII, Ans, historial y constantes C.
- H1d: EN-RE-24..30 — idempotencia triple, equivalencia, cross-engine Lite↔Plus, piecewise, share-link y persistencia.

Fuente canónica: matriz_entrada_sintaxis_calculadora, Parte H.1 (30 filas EN-RE-01..30).

Criterio de cierre: 30/30 clasificados como PASS automatizado o GAP manual/capability explícitamente documentado. Ningún skip silencioso cuenta como PASS.
